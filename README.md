# BELT FIRE

スマホブラウザ向けのコンベア工場パズルの最小プロトタイプです。

## 起動

依存関係をインストールし、Viteの開発サーバーを起動してください。

```bash
npm install
npm run dev
```

ブラウザで表示された `http://127.0.0.1:5173/` を開きます。

公開版は [GitHub Pages](https://yukinooooooosan.github.io/beltfire/) で遊べます。`main`ブランチへpushすると、テストとViteビルドの成功後に自動更新されます。

通常はPhaser版Rendererで起動します。旧Canvas版との比較は
`http://127.0.0.1:5173/?renderer=canvas` で行えます。

Mission 02は `http://127.0.0.1:5173/?mission=2` で直接開始できます。Mission 01をクリアして「次のミッション」を選ぶことでも移動できます。

設計上のモジュール境界と将来のPhaser移行方針は [`ARCHITECTURE.md`](./ARCHITECTURE.md) を参照してください。

## Mission 01

- 2×2マスの炎発生装置から、2×2マスの炉へ火を10個届ける
- 両装置にはそれぞれ独立した2つの出入口がある
- 1本のベルトでもクリア可能で、2本なら並列搬送できる
- 炉の正面カウンターに受け取った火の個数を表示し、納品時に発光する
- 火は炎発生装置の2つの内部出力室から、最初のベルトへスライドして射出される
- ミッション開始時は一時停止。右上の再生／停止ボタンで工場全体を制御できる
- 一時停止中もベルトの敷設や撤去ができる
- ベルトは別々のドラッグで敷いても、終端と矢印が隣接すれば接続される
- 既存ベルトの終端からドラッグして延長・方向変更できる
- 火はグリッド上の判定を保ったまま、セル間を滑らかに移動する
- 火がベルト上で滞留すると、そのベルトへ着火する
- 火災後の接続された燃え滓は、一括撤去1回でまとめて除去できる
- 通常ベルトはハンマーと金属片、燃え滓は起点から伝播する灰・煙の崩壊演出で撤去される
- 一括撤去は3回まで。ゲームオーバーはなく、任意でリセットできる
- ブラウザのタブやアプリを離れた場合は自動的に一時停止する

## Mission 02

- 2×2マスの電気発生装置から、2×2マスの貯水タンクへ水を10個届ける
- 施設パレットにある縦1×2マスのポンプ2台を、プレイヤーが盤面へ配置する
- ポンプは下から電気を1個受け取り、上のベルトへ水を1個送り出す
- 出力先がない、またはベルトが詰まっている間は電気を保持し、それ以上の電気を受け取らない
- ポンプ1台でもクリア可能で、2台を並列運転すれば早く達成できる
- 配置したポンプは撤去してパレットへ戻せる。保持していた電気は撤去時に失われる
- 一時停止中にポンプ配置とベルト建設を済ませてから、工場を稼働できる

## Renderer

- Coreのグリッド、搬送、変換、滞留、着火、納品判定はPhaserに依存しない
- Phaserは設備、ベルト、火・電気・水、建設プレビューを描画する
- 射出、納品、着火、燃え滓化、クリア時にパーティクルと効果音を再生する
- 納品時は炉だけを軽く拡大し、着火・クリア時は控えめなカメラシェイクを使う
- 一時停止中はCoreと工場アニメーションを停止し、DOMの建設UIは操作できる
- WebGLが利用できない環境ではPhaserのCanvas Rendererへ切り替える
